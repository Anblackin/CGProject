## C.1 可配置几何模型

太阳系场景的可见天体复用同一套参数化几何。球体采用经纬度网格：将经度等分为 `segmentsU` 段、纬度等分为
`segmentsV` 段，纬度 `θ = πj / segmentsV`（`j = 0` 为北极），经度 `φ = 2πi / segmentsU`。顶点位置与法线为

```
p = r (sinθ cosφ, cosθ, sinθ sinφ)
n = (sinθ cosφ, cosθ, sinθ sinφ)
```

其中 `r` 为显示半径。该参数化使太阳与八大行星共用一份网格生成代码，仅需改变半径与网格精度。
在极点处若干顶点几何位置重合，对应的三角形面积为零；生成器在建立索引时跳过这些退化三角形，
避免透视正确插值时的除零。三角形绕序统一为从球外观察逆时针，测试逐三角形验证 `cross(b-a, c-a)`
与三角形质心的点积大于零，从而保证背面剔除不会错误丢弃正面。

UV 采用等距圆柱投影 `u = i / segmentsU, v = j / segmentsV`。经度接缝处保留两组顶点：它们的
位置与法线相同，但 `u` 分别为 0 与 1。这种「几何共享、UV 断开」的做法使纹理采样端的
`Repeat` 环绕模式可以在接缝处自然连续，而不必在着色器里对 `u` 做特殊判断。

土星环与轨道细带使用同一个圆环生成器。圆环位于 XZ 平面，由内半径、外半径、径向段数、圆周段数四个
参数确定。上下表面分别生成顶点：上表面法线为 +Y、绕序从 +Y 观察逆时针；下表面法线为 -Y、绕序相反。
这样背面剔除仍可正常开启，从环平面下方观察时也能看到正确明暗。环带 UV 中 `u` 沿圆周、`v` 沿半径，
便于使用一维的径向条纹纹理表达环缝。轨道细带是该生成器的特例：宽度很小、径向仅一段、使用不受光的
示意材质，用于在不干扰主体的前提下显示公转轨道。

## C.2 纹理采样与颜色空间

磁盘纹理以 8 位 sRGB PPM 文件保存，读取时按 sRGB 传递函数解码为线性浮点 RGBA：

```
c_linear = c_srgb / 12.92                      (c_srgb ≤ 0.04045)
c_linear = ((c_srgb + 0.055) / 1.055)^2.4      (otherwise)
```

所有采样与着色在线性空间进行；线性到 sRGB 的转换只在最终显示阶段执行一次，避免中途多次 gamma
变换改变明暗关系。采样器提供最近邻与双线性两种过滤，以及 Repeat、Clamp、Mirror 三种 UV 环绕方式。
双线性采样以像素中心为坐标基准（`(i+0.5)/n`），在四个相邻纹素间插值；Repeat 环绕保证球面接缝两侧
采样到相同的纹素组合。为便于独立验证，模块内还生成了三类程序化纹理：棋盘格用于检查过滤与环绕，
经向条纹用于行星测试，带暗缝的径向条纹用于土星环。

## C.3 材质与光照

材质接口把「颜色来源」和「光照方式」分开。颜色来源可以是常量 `baseColor`，也可以是
`baseColor × albedo 纹素`；光照方式分为自发光、无光照与受光三类。

太阳采用自发光材质：最终颜色为自发光色与纹理色的乘积，不参与法线点乘计算，因此从任何角度观察
亮度一致。轨道细带采用无光照材质，直接返回基色，避免暗面时轨道消失。行星与环带采用
Lambert 漫反射加常量环境光：

```
C = A · (k_ambient + k_diffuse · max(0, N·L) · I)
```

其中 `A` 为线性反照率，`N` 为插值后归一化的世界空间法线，`L` 为由着色点指向太阳的单位方向，
`I` 为光源强度。环境项保证背光侧不会全黑，便于观察暗面轮廓与采样差异。
着色函数实现为纯函数：输出只依赖材质、插值输入与光源，不访问帧缓冲或深度。对 SSAA，每个子样本
调用一次；对 MSAA，每个被三角形覆盖的像素按约定位置求值一次。这样的接口使着色计数可以直接作为
抗锯齿实验的观测量，而不会改变合成逻辑。

环带的双面几何在光照上按各自法线处理：上表面与下表面分别用 +Y 与 -Y 法线计算 `N·L`，
避免用一个面片的正反面共用同一法线导致其中一面错误变暗。

## C.4 资源来源与可复现性

为便于演示程序换目录后仍能运行，模块 C 的测试纹理全部由代码程序化生成，不依赖外部图片文件；
同时保留 PPM（P6）读取接口，后续若有 NASA 公开行星贴图，可直接放入资源目录并在材质中替换
`albedo` 指针。PPM 格式简单、无压缩、便于核对像素值，适合作为光源与反照率的基准数据。

几何与光照参数均不采用真实天文尺度，展示比例与物理参数分别标注；太阳位于世界原点，
八大行星按 A 模块的参数表放置在 XZ 轨道平面上。这样既保证视觉演示可读，也避免把展示尺度
误当成物理结论。模块自带的自测覆盖球面法线长度、接缝 UV、三角形绕序、环带双面法线、
纹理环绕连续性与光照分支等 27 项检查；独立渲染 demo 输出带纹理光照的球体与环带图像，
可作为 11 月 18 日「带纹理球体闭环」里程碑的核对材料。
